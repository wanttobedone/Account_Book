# 日常账本

一款可以离线记录每日收支的安卓应用，支持收支日历、自定义分类和账本备份。

用安卓手机打开[最新发布页](https://github.com/wanttobedone/Account_Book/releases/latest)，在附件中选择以 `.apk` 结尾的文件安装。已经安装旧版时，选择覆盖更新可以保留账本。

从 0.2.1 起，在「设置 → 应用更新 → 填写网址」粘贴下面的地址并保存。以后点「检查更新」即可查看新版。

```text
https://github.com/wanttobedone/Account_Book/releases/latest/download/latest.json
```
